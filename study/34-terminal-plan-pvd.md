## 核心创意:PVD(Predict-Verify Dispatch)三层调度

与 ocean 的单物理轴阈值比较(泛用但粗)对照,我们的调度器三层递进,每层有明确的物理
出处与验收口径——这是论文的架构贡献(C3):

```
L0 矩阵级:管线形态选择(dense_mode/直写族/混合)——已有,纳入统一框架
L1 行级预测:成本模型 argmin —— 每武器一条解析成本律,系数由 oracle 标定
   C_hash  ≈ α·(表字节/SMEM预算)(占用物理) + β·flop(探测链) + 截距
   C_dense ≈ γ·span(窗扫) + δ·flop(逐乘积原子)
   C_k7    ≈ ε·span(位图清/扫) + ζ·flop(标记+rank 写)  [dup 证书域内]
L2 核内证书:验证式快道 —— k7 的 count 证书(flop−distinct≤CAP)已落地;
   推广:每武器声明合法域证书,预测错 → 核内当庭降级(不越界不静默)
```

**新颖点(论文话术)**:
1. **Predict-then-Verify**:路由=预测(argmin),正确性=核内证书兜底——静态门做不到的
   "边际行安全定价"由证书解决(c-43/Si10H16 教训的直接产物)
2. **物理先验 × 实测标定**:成本律形态来自机理(占用物理/dup 轴/位图经济学),系数来自
   oracle 逐行计时——不是黑盒分类器,每个系数可解释(鲁棒架构铁律的正面示范)
3. **离线标定,零在线学习**(ADAPT_EXPAND 08-30 判负 + "根据答案出题"否决的合规形态)
4. 评估框架:**oracle-gap**(调度器 vs 逐行最优的比值)作为调度器质量的头条指标
