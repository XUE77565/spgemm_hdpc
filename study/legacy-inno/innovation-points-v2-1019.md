## 贡献一(头条):三层路由调度架构——首个管线配置级的分发系统,部署实测

**主张**: SpGEMM 的矩阵级调度应按**可判定性分层**:解析可解的不学习(预门/带状规则,
O(n) 特征零成本)、结构可判的用规则(logit 公式,5 参数)、物理不可约的才留给学习;
层间用**运行时证书**兜底(hash 溢出→merge3 形态回退)。

**系统**(全部在二进制内,`METHOD=adaptive` 一条命令):
```
n≥5000 ─┬ skew>1700∧avg<10 → hash·C 配置(带状族路由)
        └ 其他 → hash·A 配置(预门,跳决策机器)──溢出证书→merge3 兜底
n<5000 ─┬ avg<2∧n≥10k → hash(退化否决)
        └ 4 变量 logit(重训)→ hash / merge3
```

**证据**:
- 部署系统 428 阵(双方基准之并)同夜配对 **GM 0.949-0.959**(两夜夹住,10-17/18,
  tag timed-confirm428);
- 逐层贡献定谳:预门 1.0331→0.9486(发现老 dispatcher 方向从没错过、亏在决策自税 4%)
  / logit 重训 f100 −5.6%(LOO 94.5%)/ 带状族路由治疗组 −30%(blowey 5.0×→1.56×);
- **部署系统超过单臂 oracle**(0.9486<0.9684)——merge3 臂不在旧选择集,调度把配置
  家族的空间吃干;
- held-out 泛化(70 阵与本轮全部拟合不相交):**调度净增益 22.3% 复现,零尾部(0/70
  >1.10)**——"针对基准打补丁"质疑的实验性结案(compare/batch437/heldout_246.csv)。

**划界**: IA-SpGEMM(ICS'19,MatNet)=单层黑盒深模型选 format+算法变体,无安全网;
ocean(ICS'26)=静态单层门;Wang 2025(TACO)=ML 选估计方法(单决策点)。我们是
**配置级分发 + 分层架构 + 证书兜底**的三合一,查新未见先例(study/report-1021/03)。

**语言纪律**: 不说"首个 input-aware";说"首个管线配置级分发 + 按可判定性分层的
裁定架构"。

## 贡献二:前沿曲线——证书必要性的实证反证

**主张**: 预运行特征的学习选择在 GM 与无回归保证之间存在**不可兼得的前沿**
(1.0012↔14 阵回归 vs 1.0141↔干净但=基线);**打破前沿的唯一路径是运行时证书**。

**证据**: 守卫参数全扫描(study/48);S3 终审:9 指控→同日 min5 协议翻案 6 无罪
→真尾 2 阵 171µs(亚毫秒单阵跨日不可作证据,6/9 翻案率);证书实战:dense 溢出
判废→merge3 回退(DCEST V3,study/40)。

**划界**: ocean 的自纠=溢出 retry(只保正确不保性能边界);无人做判废证书链+形态回退。
此贡献把"我们为什么需要证书"从口号变成曲线。

## 贡献三:机理发现群(否定结果与取舍悖论)

1. **逐行 kernel 时间 ≠ 系统成本**(集体效应;调度收益无法从 kernel 级计时预测)
   ——L0 发现,337 相位数据背书(study/37);
2. **dense_count 取舍悖论**:精确计数相位**最贵**的地方恰是消灭它**最亏**的地方
   (份额 15-25% 桶 CD/C=1.13;est 配额 margin+拷贝税随 dense 人口放大)——
   "不偷生态"的定量版(study/40 追记);
3. **SiO2 翻面**:修管线改变最优调度(A 超默认 C 3.75%)——"先修管线再学调度"
   的方法论依据;
4. **基准碎片化**:first100/ocean337/HSMU338 两两重叠 ≤1 阵(实测)——领域自选战场
   互比,428 并集=正面回应。
