## S3 设计(10-29 晚,S2 结论驱动)
**S2 核心洞察**:固定几何改变(32→16→8 lane)在 bin0(est 33-55)不产生收益,
因为每行有 33-55 个乘积,即使 B 行短,32-lane 也只有少量空闲 lane——
**每行工作量足够饱和一个 warp,行级并行度不是瓶颈**。
**S3 正确形态:不是改 lane 数,是改每行的工作分配策略**:
```
当前 batched:warp-per-row,j 32 路并行(对所有 B 行长统一)
S3 自路由:  warp-per-row,但 j 的分配按 B 行长自适应:
  - B 行 ≤ 4:  j 串行(lane 0 独占,免 ballot/sync 开销)
  - B 行 5-16: j 8 路并行(每 lane 处理 1-2 个 j,减少 sync)
  - B 行 > 16: j 32 路并行(当前行为)
```
这不是"多行共享 warp"(multirow 的思路),而是**同一行内按 B 行长动态
分配 lane 数**——真正利用行内异质性(B 行长在 3-60 之间变化)。
**实现**:batched kernel 内,k 循环里读 B 行长 blen=ke-ks:
  if (blen <= 4) { lane 0 串行处理 } 
  else if (blen <= 16) { 8-lane 组 } 
  else { 32-lane(现有) }
核内 if-else,无额外内存读取,决策表可由模型后期生成。
**验证**:合成异质格网(混合 B 长行人口:50% B=3 + 50% B=30)vs batched;
预期:短 B 行免 sync 开销,长 B 行保持满并行,异质人口净赢。
