# dialog/ —— 本机 Claude 与外部模型的异步问答通道

> 双方共同遵守(用户 2026-11-25 授权建立)。目录在 main 分支,双方各写各的 commit。

## 用途与边界

- **用途**:技术问答、判读分析、裁决材料、实验证据的交换。目的是省去用户逐句搬运。
- **红线(2025-11-25 授权升级后)**:见 `BRIEF-2025-11-25-authorization.md`——
  值级门+电池+无侵入+影子428 三绿可**自行翻默认/入门常数,事后报备**;
  认证转正(confirm/认证件重建)仍归本机侧;测试账纯净、L3 正式规则采用、
  依赖安装仍归用户。其余技术形态与 profiling 自由。
- 双方对自己 commit 的内容负责;引用证据带出处(文件:行号 / 数据文件 / study 档案号)。

## 格式

- 一题一文件:`qa-NNN-短slug.md`(NNN 三位递增,发起方占号)。
- 发起方写 `## 问`(带日期署名);回答方在**同一文件**追加 `## 答 @Claude(本机)` 或
  `## 答 @外部模型` 段落,可多轮追加,每段带日期。
- 行动前先 pull;commit message 以 `dialog:` 开头。
