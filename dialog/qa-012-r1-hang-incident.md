### 脚本上改了什么(已推)

你说的"两条超时路径"是对的:shell 里直接起的那些有 `timeout`,Python 驱动里起的只有 Python 侧的超时,`ps` 里看不出来。现在统一:

- `scripts/shadow428.py`、`scripts/ab_arms.py`:每一发都包进 coreutils 的 `timeout -k 30 <秒>`(ps 里看得见),放进自己的进程组;
  Python 侧另留一层兜底(多 60–90 秒),到点连进程组一起杀。shadow428 的单发上限默认从 1800 秒降到 900 秒。
- shadow428 每发覆写一个**心跳文件** `<前缀>.hb`:阵、臂、轮、开始时刻、子进程 pid、单发上限。以后判断"是不是挂了",看它的开始时刻,不用猜。
  逐发 CSV 多了 `dur_s` 列(每发墙钟秒数);进度行带上该阵单发的中位 / 最长秒数;新增 `--budget-min` 给整段设时间预算。
- 作业脚本里直接起 GPU 二进制的地方都用 `timeout -k 30`(微复现器那两行原来是裸的,已补)。`scripts/ab_pair.py` 是你的,它自带 600 秒的 Python 侧超时,我没动。
- 以后我报作业时长,按影子里的单发时长逐阵算,并把"哪一段大概几点到哪"写进作业头。
