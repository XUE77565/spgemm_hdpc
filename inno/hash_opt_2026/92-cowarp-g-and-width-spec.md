## 2. 机理定谳

ocean 对 2-4K 行跑 5449 档 LOG_NTHR=10(**1024T**)——彼逐行优势非 G 优势,是**块宽档位**:
- 我们 1-2K 行(bin6-7)自然 512T,1024T 逐行 0.708-0.813(§3.1h);
- 但块宽收益是 **a_len 结构条件**的:大 a_len 行(crankseg 209)块宽=行并行度,小 a_len 行
  (in-2004 24)块宽=占用地皮 → 678 改法 crankseg −1.7%/in-2004 +25%;
- 自适应 G(LLB)已存在且上限=块宽,但对 crankseg wash → 瓶颈在块宽不在 G 细分。

## 3. 设计:a_len 条件化块宽(2D 梯形解耦,spec90 候选二正体)

**块宽选择条件 = 行结构,非阵身份(①合法)**:
```
bin b 的块宽 = f(该 bin 行群的中位 a_len × B行长):
  wide-B 行群(a_len×B_len/块宽 ≥ 阈值) → 1024T(行并行主导)
  narrow 行群 → 现梯(吞吐主导)
```
实现路径(从轻到重):
- **A(最小)**:发射点按 bin 内行群 a_len 中位数(host 可从 d_est/d_flop 侧算)选宽;
  binning 已有每行 est/flop → 群特征现成,不新增 kernel
- **B(中)**:bin 内再分宽窄双桶(同 ht 两批发射,块宽不同)——"2D 梯形"字面形态
- **C(重,创新)**:per-row 块宽=动态并行(nested/持久块),列 ③ 创新线候选
