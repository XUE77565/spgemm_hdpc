# spec96b: col/val 交织表布局——解析判死(09-24 08:2x 日班#2)

- **设想**:16B 槽 {int col; int pad; double val} → LDS.128 一条取 col+val,命中路径
  LDS+LDS.64 → 1 条(§3.1x 最后未试族:减事务不动分支)。
- **判死数学**:①命中路径两次 LDS 各司其职——col 读做判定,val 读在 F64 CAS-spin
  **内部**(重试需最新值,不可提升/不可预读,预读仅在首发 CAS 成功时有价值=低概率)
  → 交织实际省 0-1 条 ②带宽反升:16B×32 lane=512B/warp(vs col 128B+val 256B=384B),
  LDS.128 硬件 4 相位下限,随机槽 4 槽 bank 域 ③26 引用点全改(extract/CSORT/WM 顺带
  承受顺序扫描的相位下限) ④SMEM +33%(pad)。
- **结论**:期望负收益,不实现。§3.1x 四族(装载重排/双链/聚合/交织)至此全评估完,
  探测环的 per-product 形态在我方结构内已穷尽——重行剩余空间在结构外(新载体=③线)
  或接受现状。与 spec93/94/95/96 共同构成"探测环改进的完整负结果地图"。
