## Phase 0(7 月):比赛起点——武器库与第一个 dispatcher

**做了什么**:17 相位 hash 管线(hash_spa/档位梯/csort)+ merge3(列域分桶 warp-merge)
+ **O(1) 四变量调度公式**(flop_proxy/n/maxrow/skew 的 logit,100 阵拟合,准确率 95%)
+ hash 溢出→merge3 自动回退(证书思想的原型)。

**数字**:first100 对 ocean **0.6224**(赢 81/19)——"小阵碾压"的基本盘在此建立;
ocean337(其自选中大阵)无生态位,系统落后(约 1.37-1.65 时代,口径跨代仅趋势)。

## Phase 1(8 月-9 月上):kernel 与七武器 arsenal

**做了什么**(dense/cursor 攻坚线 + 档位梯):
- dense_struct 梯子(巨鲸行 0.46-0.78× vs ocean)/cursor(0.83-0.88×)/微行族(0.406×)
  /hash_heavy SPEC99(in-2004 0.726×,胜率 100%)/**merge3 dense 单遍直写**(08-31,
  count 5.2×/numeric 2.26×);
- csort 梯 v2/CNT、bin7、K7 双遍位图、结构化参数终审;
- **方法论沉淀**:口径先行+SOTA 代码级对照、守门三件套(值级/有序/memcheck)、
  GPU 保护纪律、外部基线借鉴铁律。

**数字**:kernel 级同行集 hash 三阵全胜;系统级 c-64 0.974-0.981 旗舰;
T10 广域 52 阵 1.653(10-05 口径)。**局限**:拼图式优化,GM 兑现被乘性稀释。

## Phase 2(9 月-10 月上):架构觉醒——从 kernel 到系统

**关键发现(论文级)**:
1. **逐行 kernel 时间 ≠ 系统成本**(集体效应:launch 税/占用交互/仪式开销)——
   L0 系统级调度架构的原理性依据(study/37,用户钦定 10-10);
2. SiO2 翻面首证:修管线改变最优调度;
3. **口径权威化**:ocean_337 同日专测基线(10-11),此后一切记分有唯一事实源。

**做了什么**:

   →证书必要性);

## Phase 4(10-17→10-19):部署、泛化与 kernel 收官

**做了什么**:
- **三层路由落地二进制**(一条命令 METHOD=adaptive):
  预门(法医分析发现老 dispatcher 方向从没错过、亏在 4% 自税 → 1.0331→**0.9486**)
  + logit 重训(91 真实标签,f100 −5.6%)
  + 带状族路由(结构画像 → 治疗组 −30%)
  + 退化否决;
- **确认批两夜**:0.9486/0.9588(两夜夹住真值,夜漂移定位到微阵协议);
- **held-out 泛化终审**(70 阵不相交人群):调度净增益 22.3% 复现,**S3 零尾(0/70)**;
- **口径源码级审计**(ocean epilogue 在计时圈内获行号级证明)+ 泄露悲观界(0.9979);
- **K 链**:网格族诊断(带宽取证:拷贝仅 8-16% 峰值)→ **FLAT 条目级并行拷贝**
  (受影响组同会话 **+9.1%**,网格族 −24~−40%,对 ocean 2.2-2.4×→1.4-1.8×);
- merge3 dense 双雷修复(SASS 审计,dense 人群 +13-17%);
- 论文创新点定稿 v2(五贡献)。
