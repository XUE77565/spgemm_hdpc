# tools/train_synth —— 合成训练阵(两遍式行门 HH_BM2_FX 的标定来源)

- **是什么**:`gen_synth.py` 按固定参数表和固定种子生成 14 个方阵(W ∈ {112, 224, 448, 900, 1800, 3600, 7200} × 步长 s ∈ {1, 16}),
  把"每行乘积数 flop ÷ 哈希表长 HT"这个量铺到 1…192。参数表、结构与种子都写在脚本文件头里。
- **为什么**:`data/train_disp` 的真实训练阵在这个量上只到 8 左右,两遍式对哈希的逐行周期比到头时贴近 1 还没越过;会输的行在 10 以上。
  门值不能看着测试账(428 / flex142 / external_72)定,所以用受控结构把量程补上(dialog/qa-013,B 端批准)。
- **纪律**:合成阵是训练数据,不属于任何测试账;只在作业目录里现生成(`$JOB_DIR/train_synth/`),用完即删,**不进 git、不放进测试账的数据目录**。
  要复现,用同一版脚本重跑即可(种子固定)。改了参数表就是另一批训练阵,要在这里和 study/69 里记一笔。
- **为什么放在 tools/ 而不是 data/train_synth/**:作业开跑时会把仓库根下的 `data` 建成指向 C 上数据目录的符号链接;
  仓库里若有一个真的 `data/` 目录,这个链接会建歪。所以生成器放 `tools/train_synth/`,产物放作业目录。
- **用它的作业**:`syn_c1`(逐行配对标定 → `scripts/bm2_gate_cal.py` → `scripts/bm2_fx_cross.py` 出 R(flop/HT) 曲线与 R=1 交点)。
- **由此定下的常数**:待 `syn_c1` 出结果后填(HH_BM2_FX = 0.65 × 各值区模式、各 bin 交点的最小值;428 只作定向复验)。
